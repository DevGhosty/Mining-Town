## Optional Main Street art

Download [Cainos Pixel Art Top Down – Basic v1.2.3](https://cainos.itch.io/pixel-art-top-down-basic).
In the Unity project that contains the Mining Town prototype, choose **Tools → Mining Town → Import Cainos Art** and select the ZIP. Enter Play Mode to see the terrain and props. The imported files are local to each developer's project under `Assets/MiningTown/Resources/MiningTownCainos`. The original terrain and geometry provide a fallback.

## Player sprite

The explorer's directional idle and walk frames are adapted from [Kettoman's Free Pixel Character Base Pack](https://kettoman.itch.io/free-pixel-character-base-pack-32x32-top-down-farmer-animations), released under CC0 in the download. The atlas is cropped and recolored for Mining Town.
